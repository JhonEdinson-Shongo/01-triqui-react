# Triqui React

¡Bienvenido al clásico juego de Triqui (Tic-Tac-Toe) desarrollado con React!

[![image](https://github.com/user-attachments/assets/e24c0e69-01c3-4c6c-ad49-5660d0501bb2)](https://jhonedinson-shongo.github.io/01-triqui-react/)

## Descripción

Este proyecto implementa el juego de Triqui utilizando React, ofreciendo una interfaz intuitiva y una experiencia de juego fluida. El juego permite a dos jugadores alternar turnos para marcar sus símbolos (X u O) en un tablero de 3x3. El objetivo es alinear tres símbolos iguales en horizontal, vertical o diagonal para ganar la partida.

## Características

*   Interfaz de usuario interactiva y fácil de usar.
*   Lógica de juego completa que detecta automáticamente al ganador o un empate.
*   Diseño responsivo para adaptarse a diferentes tamaños de pantalla.
*   **Próximamente:** Implementación de efectos de sonido para mejorar la experiencia de juego.

## Tecnologías utilizadas

*   React
*   HTML
*   CSS

## Cómo jugar

1.  Clona este repositorio: `git clone https://github.com/JhonEdinson-Shongo/01-triqui-react.git`
2.  Navega a la carpeta del proyecto: `cd 01-triqui-react`
3.  Instala las dependencias: `npm install`
4.  Inicia el juego: `npm start`
